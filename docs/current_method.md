# 目前程式的流程與資料契約

## 觀測與來源狀態

目標為 T；重建端是 O₀；外部來源是 O′ᵢ。來源裝置只需按協議提供影像、來源ID、拍攝時間、相機內參與拍攝位姿。姿態偵測、編碼、GRU、評分與重建皆在 O₀ 計算。目前程式讀取預先提取的逐幀回放封包，用以模擬這個順序，不是已完成的即時網路程式。

每筆觀測包含13×2像素座標、13個[0,1]信心、人物框及整體觀測是否可用。不可用觀測仍是一筆已收到影像的處理結果；和封包完全未到達不同。目前 compact 編碼只接受整體視角可用性，拒絕各關節混用的缺失遮罩。可用性不等於物理可見性，也不保證身份或關節正確。

本機每關節 `[normalized_x, normalized_y, confidence, rate_x, rate_y]` 共65維，附加 `[center_x/scale,center_y/scale,log1p(scale),log1p(previous_gap),view_available,rate_available]` 共71維。`scale=max(box_width,box_height)`；rate使用各幀自己的框正規化位置差除秒數，包含人物、相機與框的影響，不是世界速度。來源每關節 `[normalized_x,normalized_y,confidence]` 共39維，加 `[view_available,log1p(capture_gap)]` 共41維。

本機 MLP71→128→64 得 E；GRU64→64 在每輪處理最近最多4筆重新編碼的本機觀測，初始隱藏狀態為零，得到 Q。來源 MLP41→128→64 得 E′；來源 GRUCell 以新 E′ 和對應舊 H 更新 H64，來源沒有新觀測時不執行 GRU。

狀態字典 `SourceStateBank.records[source_id]` 保存 `hidden`、`observed_at`、`requested_at`、`camera_to_world`、`intrinsics`、`update_count`。其中 `observed_at` 是最新影像的拍攝時間；資料年齡在決策時以 `now-observed_at` 計算。`requested_at` 記錄請求嘗試，不能用來把未收到影像者的資料年齡歸零。update_count僅供除錯追蹤，不進入網路。

## 回合邊界

初始化一次取得全部來源。第k輪依序為：

1. 本機影像處理，產生 Eₖ、Qₖ。
2. 讀取 Bₖ 中每個來源已保存的 H、拍攝時間與相機資訊，計算年齡及幾何。
3. 共用評分頭計算本機與來源分數，再決定 Sₖ；此步不能讀取本輪遠端封包。
4. 向選中的來源請求當前影像。回放程式在此才取得相應封包。
5. 取得新觀測後，逐ID更新對應 H 和 metadata，形成下輪可讀的 Bₖ₊₁；其他來源原值保留。整批回應驗證失敗時不部分寫入 H 或相機資料。
6. 當前本機及選中取得的外部觀測進行幾何融合與重建，再進入下一輪。

這是同步回放約定：本輪請求在本輪取得並更新，**新的來源記憶到下一輪評分才會讀取**。沒有把通信延遲設定成固定一幀。融合可以在本輪使用實際取得的新影像，不從舊記憶解碼假關節。

## 幾何與評分

相機使用整流後針孔 K3×3、camera-to-world T4×4。以水平投影光軸和 `atan(width/(2fx))` 近似水平半視野，生成半徑5m扇形。5m是工程設定，非硬體規格或遮擋模型；需敏感度實驗才可宣稱最佳。整流後 width1408、fx704 對應約90°，不能直接拿 Aria 原始魚眼110°替代。固定相機各用自己的 K。

交疊值為交集面積除以本機扇形面積，非IoU。光軸內積是兩相機世界座標前向單位向量內積。相同交疊與夾角仍可能對應不同場景，不足以唯一描述遮擋。選擇前的移動來源位姿使用最近已取得值，非免費取得當前姿態。

G9實際排列為 `[overlap,0,0,optical_dot,overlap_available,0,0,1,log1p(geometry_age)]`。兩個未使用的幾何欄位因既有格式保留為零，圖中不將其畫成額外物理量。固定相機geometry_age為零；來源觀測age仍可能增加。

`Z=LayerNorm(Linear([H64,G9,log1p(A)]74))`。同一評分頭128→64→32→1計算 `[Q,LN(E)]` 及 `[Q,Z]`。分數是任意實數，非ViTPose信心。Attention對照是在相同本機／來源內容上做4-head self-attention＋殘差LayerNorm，再進入相同Q／評分頭；沒有另一套來源或本機頭。

選擇所有分數大於本機的來源。年齡達1s的來源另依最早到期時間排序，強制加入最前1個；每輪重新產生排序，不會因未排到而重複入列，取得更新後自然移到隊尾。這個1個是強制重訪名額，沒有把所有選擇限制為1個或2個。

Random matched count對照使用Learned同一幀的選擇數及強制重訪ID，其餘名額以固定亂數種子抽取，因此是控制請求數與重訪條件的比較，並非獨立執行另一套重訪排程。

## 三角化與重建邊界

所有實際取得的當前視角統一做信心加權射線最小平方；信心至少0.15、視差至少2°、重投影誤差最多24px且深度正值才保留三角化。幾何條件不足使用最高信心單視角、以頭部距離近似深度。狀態0為缺失、1為回退、2為三角化。

輸入 Exo 的13×3值是頭部相對座標轉到頭部座標系並乘信心的幾何表示。既有40→512投影保留，52→512可訓練殘差適配層處理三角化分支；圖中合稱 Exo embedding。這個適配層已存在於上一版串接，本次沒有新增信心 ScoreNet。重建使用96幀既有Transformer，不保證最終姿態逐幀因果。

EgoNet的頭部與雙腕輸入屬於目標T，不是觀測者O₀。實驗從目標SMPL FK取得追蹤，地板來自參考姿態，結果僅能按這個條件解讀。

## 損失與快取

適配層階段：全部外部視角，最小化22關節三維位置平均歐氏誤差，其他重建權重與選擇器不更新。

評分器階段：凍結適配層。在最多8來源的離線資料中枚舉子集，每隔8幀算標籤；一個被測幀更換子集，其餘96幀視窗維持固定隨機雙來源背景。令子集能量為被選來源的 `sᵢ-s₀` 總和，以softmax得到合法子集的分布，強制重訪來源必須包含。損失為期望的 `(MPJPE_m + cost×請求數)`，再加熵正則（實作是負熵，溫度0.0005m），共同除以0.005m調整尺度。預設cost0.002m＝每額外請求2mm成本。基準最小值的扣除不影響梯度。

訓練以Bernoulli採樣來源維持探索的記憶歷史，部署評估使用嚴格大於本機的決策；此處沒有額外REINFORCE損失。快取綁定適配層checkpoint雜湊、replay雜湊、目標、來源順序、幀數與stride，避免兩個模型共用錯誤標籤。這些局部反事實標籤不保證對整段閉環記憶策略最優，更多epoch也不保證誤差持續下降。
